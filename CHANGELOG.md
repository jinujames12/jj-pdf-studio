# Changelog

All notable changes to this project are documented here. The format is based on
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and this project follows
[Semantic Versioning](https://semver.org/).

## [1.0.2] - 2026-10-21

### Changed

- New logo and app icons (white PDF page with "JJ" on the brand blue), with light, dark, mark,
  one-colour and horizontal variants in `assets/brand/`.

## [1.0.1] - 2026-10-21

### Fixed

- PDFs opened with "Open with" or a double-click now open in the app instead of an empty window.

### Added

- The installer registers JJ PDF Studio as a PDF handler. Opening another PDF while the app is
  running opens it in the existing window.

### Changed

- Publisher and copyright now read James & James LLP.

## [1.0.0] - Unreleased

### Changed

- M8 Page Editor: "Pages" is now **Page Editor**, and Rotate, Split, Extract and Page numbers
  moved into it (toolbar, right-click menu, options panel, live preview on the grid). Their options
  are unchanged. Split and Extract now work on the pages as edited, including unsaved edits, and
  page numbers are an undoable edit written on Save. The sidebar has 10 entries; the home screen
  keeps a card for every task, and the old routes (`/pages`, `/split`, `/extract`, `/rotate`,
  `/page-numbers`) open the Page Editor with the matching panel. New: Duplicate, Move to
  start/end, Select menu (odd, even, range, landscape, portrait, invert), thumbnail zoom, "+"
  between thumbnails to insert a blank page. `pdf-core` gains `split_edited_with` and
  `save_edited_with`; `npm test` runs the new frontend tests.
- Page Editor keyboard use: Ctrl+D duplicate, Ctrl+Shift+S, Ctrl+E and Ctrl+Shift+N toggle the
  Split, Extract and Page numbers panels, Esc closes the panel (and returns focus to its toolbar
  button). The page grid is a tab stop with a visible ring on the current page; arrow keys move
  along the toolbar; Shift+F10 or the menu key opens the page menu; the right-click menu shows a
  focus ring on the highlighted entry.

### Added

- M8 polish: sidebar tools grouped under Organise, Convert, Optimise, Security and Edit; a
  progress bar with a Cancel button (or Esc) for every job that writes a file, backed by
  progress and cancellation in `pdf-core` (cancelling leaves no partial file behind); Ctrl+O on
  Home and About and F1 for a keyboard shortcuts list; About shows the build date, links to the
  source and issue tracker, the shortcuts and the third-party licenses
  (`THIRD_PARTY_NOTICES.md`, generated by `npm run notices`); accessibility pass (labelled
  icon buttons, skip link, dialogs that keep keyboard focus); README screenshot placeholders.
- M0 scaffold: Tauri 2 + Svelte 5 + TypeScript app, `pdf-core` library crate, design tokens with
  light and dark themes, custom title bar, collapsible sidebar, home screen and placeholder tool
  views, About screen, CI and release workflows.
- M3 tools: Merge (file view and page view, optional bookmarks that keep each file's own
  bookmarks), Split (every N pages, by ranges, at markers), Extract (one PDF or one per page) and
  Rotate (all, odd, even or chosen pages, make portrait or landscape). All write new files and
  never overwrite existing ones.
- M4 tools: Images to PDF (JPG, PNG, BMP, GIF, TIFF, WebP; JPEGs embedded without re-encoding,
  PNG transparency kept, EXIF orientation honoured; page size, orientation, margin, fit and quality
  options; one PDF or one per image) and Resize (A4, A3, A5, Letter, Legal or custom; fit, fill or
  size-only; links and comments move with the page).
- M5 tool: Compress with three presets. Lossless removes unused data and thumbnails, compresses
  plain streams, merges identical streams and packs objects into object streams. Balanced and
  Strong also recompress large JPEG and Flate images (RGB or gray, with or without a soft mask) at
  a lower resolution, judged by the largest size each image is drawn at. Images the tool does not
  understand pass through unchanged. Nothing is written when the result would not be smaller, and
  the result dialog shows before and after sizes.
- M6 tools: Unlock (saves a copy without an open password or restrictions; explains which kind
  the file had and why copying can still fail, for scanned pages and fonts without a Unicode map)
  and Protect (AES-256, optional restrictions with a separate owner password). Every tool now asks
  for the password when a protected PDF is opened. Reads RC4 40/128-bit, AES-128 and AES-256.
- M7 tools: PDF to Images (all or chosen pages as PNG or JPG at 72, 150, 300 or a custom DPI,
  written to a folder or one ZIP file; pages are drawn one at a time with a Cancel button and
  rotated and mixed-size pages keep their shape), Page numbers (six positions, formats such as
  "Page 1 of N", start number and page range, drawn with the standard Helvetica font where the
  page appears on screen, rotation and crop box included), Watermark (text or picture, opacity,
  rotation, centred, tiled or in a corner, over or under the page, page range) and Properties
  (edit title, author, subject, keywords and creator, see producer, dates, PDF version, page sizes
  and protection, or remove all metadata including XMP). Page numbers and Watermark show a live
  preview of any page before saving.
