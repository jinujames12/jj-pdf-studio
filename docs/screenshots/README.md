# Screenshots

The `.svg` files here are placeholders. To replace one, take a 1280x800 screenshot of the app
(Windows key + Shift + S), save it under the same name as a `.png`, delete the placeholder and
change the extension in the links in the top-level `README.md`.

| File          | Show                                        |
| ------------- | ------------------------------------------- |
| `main-window` | Home screen with the tool grid, light theme |
| `pages`       | Pages tool with a few pages selected        |
| `compress`    | The Compress result dialog                  |
| `dark-theme`  | Any tool in the dark theme                  |

Use a document you are free to publish (the PDFs in `tests/fixtures/` are fine).
